# Directives (Layer 1)

SOPs written in Markdown. Each directive defines:

- **Goal** — What the task accomplishes
- **Inputs** — What data or context is needed
- **Tools/Scripts** — Which execution scripts to call
- **Outputs** — Expected deliverables
- **Edge Cases** — Known failure modes and how to handle them

Directives are living documents — update them as you learn.
